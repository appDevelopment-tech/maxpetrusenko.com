# performance-analyst

## Variables

- **performance_requirements**: Specific metrics to track and analyze
- **data_sources**: Files/APIs containing performance data
- **visualization_type**: Dashboard, charts, reports format requested
- **agents_to_analyze**: Which agents or teams to focus on
- **time_period**: Historical range for trend analysis
