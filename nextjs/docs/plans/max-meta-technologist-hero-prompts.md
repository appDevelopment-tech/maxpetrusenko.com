Key strategic read:
The current homepage is clear but split into a service directory: tech card + bodywork card. The stronger story is not “I do two things.” It is “I study hidden state across systems, agents, attention, and bodies.” That makes the tech/somatic split feel like one operating system instead of two unrelated lanes.

Visual direction:

Prompt idea 1 — best / Meta-Technologist
Build a scrollytelling hero redesign for maxpetrusenko.com around “Max the Meta-Technologist.” Reframe the homepage as an identity synthesis journey: 80 articles -> 7 content voices -> 3 clusters -> 1 operating identity. Start in information overload, animate article fragments and graph nodes into clusters, then reveal Max as a meta-technologist for systems, agents, and attention. Visual style: light cinematic editorial, ivory paper, graphite ink, precise Linear-style panels, Runway-like motion pacing, one restrained violet accent. No dark mode, no generic SaaS cards. Include Parse, Segment, Synthesize, Reveal, Proof, and CTA. Preserve practical offers: AI automation, Claude Code/n8n workflows, agent personas, somatic/Mindfold work, proof/case studies. Hero line: “I decode how intelligence breaks, scales, and reassembles, then build tools and spaces that make hidden state visible.”

Prompt idea 2 — Hidden State
Design a scroll-driven homepage hero called “Hidden State.” Every section reveals one layer of invisible state: execution state in AI agents, bottleneck state in business workflows, nervous-system state in people, epistemic state in culture. Use a sticky video/canvas stage that scrubs from noisy fragments to clean architecture diagrams to a calm human portrait. Tone: sharp, calm, technical, embodied. CTA: “Bring me your stack. I’ll show you where the hidden state is.”

Prompt idea 3 — From Noise to Signal
Create a breathtaking scrollytelling homepage for Max Petrusenko where the visitor watches raw online noise compress into signal. Start with social feeds, article fragments, tabs, terminal traces, and Notion cards. On scroll, the noise is parsed into 7 content voices, segmented into 3 persona clusters, and synthesized into “Max the Meta-Technologist.” Use a light premium editorial palette, graph lines, article cards as artifacts, and a scroll-scrubbed film panel. End with “Send me your stack” and three proof lanes: automation, agent systems, embodied state.

Prompt idea 4 — The Operator Behind the Agents
Build a hero story where Max is not presented as a generic AI consultant but as an operator building with agent teams. Use gstack/gbrain as narrative metaphors: gstack = virtual engineering team, gbrain = persistent knowledge brain, Max = the human meta-layer that decides what matters. Scroll scenes: blank prompt -> role swarm -> browser QA -> memory graph -> shipped systems. CTA: “If your agents are busy but your system is still stuck, talk to me.”

Prompt idea 5 — Systems for Scale, Presence for Depth v2
Upgrade the existing homepage line rather than replacing it. Start with “Systems for scale. Presence for depth.” Then scroll reveals that both halves share one principle: state literacy. Tech section shows workflow bottlenecks and agent execution state. Somatic section shows attention, breath, and nervous system capacity. The final synthesis: “I build systems that don’t lose the human.” Use softer visuals, more human imagery, and less technical density.
